## 3. Харагдах байдал

Энэ бол өөрийн Монгол апп. X Money-ийн дэлгэцийг хуулахгүй. Лого, нэр, хүү, карт, шилжүүлэг, trading байхгүй.

Өнгө, зөвхөн харанхуй горим:

| Үүрэг | Өнгө |
|---|---|
| Дэвсгэр | `#000000` |
| Карт | `#121212` |
| Үндсэн текст | `#FFFFFF` |
| Туслах текст | `#8A8A8A` |
| Нэг accent | `#00BA7C` |

Цагаан горим энэ баталгаанд ороогүй. Улаан, шар нэмэхгүй. Зарлага болон хэтрэлтийг өнгөөр ганцаар ялгахгүй: «−» тэмдэг ба «Хэтэрсэн» гэсэн үг хамт гарна.

Контрастыг WCAG 2.x-ийн харьцангуй гэрэлтүүлгээр энэ баримтыг засах үед тооцсон. sRGB сувгийг шугаман болгоод `L = 0.2126 R + 0.7152 G + 0.0722 B`, харьцаа `(Lцайвар + 0.05) / (Lбараан + 0.05)`.

| Хослол | Харьцаа | 4.5:1 текст |
|---|---|---|
| `#FFFFFF` / `#000000` | 21.0000:1 | тэнцэнэ |
| `#FFFFFF` / `#121212` | 18.7337:1 | тэнцэнэ |
| `#8A8A8A` / `#000000` | 6.0830:1 | тэнцэнэ |
| `#8A8A8A` / `#121212` | 5.4266:1 | тэнцэнэ |
| `#00BA7C` / `#000000` | 8.3146:1 | тэнцэнэ |
| `#000000` / `#00BA7C` | 8.3146:1 | тэнцэнэ |
| `#FFFFFF` / `#00BA7C` | 2.5257:1 | тэнцэхгүй |
| `#8A8A8A` / `#00BA7C` | 1.3669:1 | тэнцэхгүй |

Сонголт: үндсэн үсэг цагаан, хар эсвэл `#121212` дээр. Туслах үсэг `#8A8A8A`, мөн хар эсвэл карт дээр. Гол товчны дэвсгэр `#00BA7C`, үсэг нь хар. Том үлдэгдэл `#00BA7C` байж болно, дэвсгэр нь хар. Ногоон дээр цагаан эсвэл саарал үсэг тавихгүй. Алдаа, хэтрэлтийг өнгөнөөс гадна «−» ба үгээр харуулна.

Үлдэгдлийн тоо 40–48pt, бүдүүн. ₮ болон аравтын хэсэг жижиг. Карт хооронд сул зай их. Товч, таб, чип хамгийн багадаа 48dp өндөр, 48dp өргөн. iOS-ийн 44pt-аас бага байж болохгүй.

Фонт: төхөөрөмжийн систем фонт. Шинэ фонт татахгүй.

## 4. Гурван тоо, гурван шошго

Нүүр дээр гурван тоо тусдаа шошготой. Нэгийг нөгөөгөөр орлуулахгүй. Аль нэгийг нь «зарцуулж болох мөнгө» гэж нэрлэхгүй.

1. **Нийт үлдэгдэл.** Зөвхөн `currency = 'MNT'` дансны `account_balances.balance` нийлбэр. Бүх үеийн MNT. Эхний үлдэгдэл орно. Өөр валютыг энэ тоонд нэмэхгүй.
2. **Энэ сарын цэвэр.** Тухайн төхөөрөмжийн календарийн сард, зөвхөн MNT дансны гүйлгээнээс, `type = income` нийлбэрээс `type = expense` нийлбэрийг хассан дүн. Өмнөх сар орохгүй. Үлдэгдэл биш.
3. **Төсвөөс үлдсэн.** Төсөвт валютын багана байхгүй. MVP дээр төсөв MNT. Зарцуулалт нь тухайн `category_id` дээрх энэ сарын `type = expense`, зөвхөн MNT данснаас. Орлого хасагдахгүй. Үлдсэн = `limit_amount − зарцуулалт`. Нүүр дээрх тоо нь эдгээр үлдэгдлийн нийлбэр. Төсөвгүй ангиллын зарлага, MNT биш дансны зарлага энэ тоонд орохгүй. Төсөв огт байхгүй бол 0 гэж харуулахгүй. «Төсөв алга» гэж харуулна.

`accounts.currency` нь `text not null default 'MNT'`. Зөвхөн MNT гэсэн check байхгүй. MNT биш данс байвал нүүрэнд тусад нь, валютынхаа кодтой, зөвхөн адил валют дотроо нийлбэрлэнэ. «Нийт үлдэгдэл зөвхөн MNT» гэж бичнэ. Ханш, банкны API байхгүй. Бүх данс MNT бол энэ тайлбар гарахгүй. MNT данс огт байхгүй бол MNT нийлбэрийг 0 мэт чимээгүй харуулахгүй. «MNT данс алга» гэж харуулна.

Сөрөг үлдэгдэл «−» ба «Хэтэрсэн» гэсэн үгтэй. Ногоон өнгө дангаараа хэтрээгүй гэсэн үг биш.

## 5. Дэлгэц

Доод таб гурав: **Нүүр**, **Гүйлгээ**, **Төсөв**. Данс, ангилал, шошго, гарах, админ таб биш.

**Нүүр.** Гарчиг «Миний мөнгө». Баруун дээд товч профайл руу. Гурван тоо. Дараа нь сүүлийн 5 гүйлгээ, огнооны бууралтаар. Нэг гол «+» товч. Хоосон, ачаалж буй, алдаа, доош татаж шинэчлэх хэвээр.

**Гүйлгээ.** Одоогийн хайлт, төрлөөр шүүлт, огноо/дүнгээр эрэмбэ, хуудаслалт, доош татаж шинэчлэх хэвээр. Жагсаалтыг календарийн сараар бүлэглэнэ. «+» энд мөн байна.

**Төсөв.** Энэ сарын төсөв бүрт нэр, «зарцуулсан / хязгаар», «үлдсэн» эсвэл «Хэтэрсэн −…». Жишээ: «45,000₮ үлдсэн / 150,000₮». Прогресс зурвас нь текстийн давхар. Зөвхөн зурвасаар мэдэгдэхгүй. Төсөв нэмэх, засах, устгахын өмнө асуух хэвээр.

**Профайл.** Одоогийн холбоос: данс, ангилал, шошго, гарах. Админ зөвхөн `role = admin`. Зочин өмнөх шиг ангилал үзэж, үлдэгдэл харахгүй. Нууц үг сэргээх, бүртгэл, нэвтрэлт хэвээр. SecureStore хэвээр.

**Гүйлгээний богино форм.** Нэг дэлгэц:

| Талбар | Дүрэм |
|---|---|
| Дүн | 0-ээс их. Хадгалахын өмнө 2 орон руу тойруулна: 0.005 нь 0.01. `numeric(14,2)`-д багтахгүй бол алдаа. Шинэ багана үүсгэхгүй. |
| Төрөл | Орлого эсвэл зарлага. |
| Данс | 0 данс бол хадгалахгүй, данс үүсгэх холбоос. 1 данс бол тэрийг сонгосон, солих боломжтой. Олон бол нэрээр эрэмбэлсэн эхнийхийг анхдагчаар сонгоно, жагсаалт харагдана. |
| Ангилал | Тухайн төрлийн ангилал. Хоосон бол хадгалахгүй. |
| Огноо | Анхдагч нь төхөөрөмжийн өнөөдөр, `YYYY-MM-DD`, засаж болно. |
| Тэмдэглэл | Заавал биш. 200 тэмдэгтээс урт бол хадгалахгүй. |
| Шошго | Заавал биш. Олон сонголт. `transaction_tags`-д бичнэ. |

Устгахын өмнө баталгаажуулна. Засах нь ижил форм.

## 6. Огноо

«Өнөөдөр» ба «энэ сар» нь төхөөрөмжийн календарийн өдөр. `src/lib/validation.ts` 43-р мөр `toISOString().slice(0, 10)` нь UTC тул Монголд өглөө өмнөх өдөр болж болно. Үүнийг формын анхдагч огноонд ашиглахгүй.

`YYYY-MM-DD` мөрийг `new Date('YYYY-MM-DD')`-аар задлахгүй. Сар солихыг мөрийн жил, сараар тооцно. `occurred_at` багана `date` хэвээр.

## 7. Мөнгө

MNT дүн мянгатын таслал, 2 аравт, ₮. Өөр валют өөрийн кодоороо. ₮-г тэр дүн дээр тавихгүй. Хасах дүн «−»-тэй. `Number` дээр хөвөгч алдаа гаргахгүйгээр 2 орон руу тойруулж хадгална. Баганын төрлийг өөрчлөхгүй. Ханш солихгүй.

## 8. Хамгаалалт ба тест

RLS, `is_admin()`, `profiles_protect`, өмчлөлийн policy хэвээр. `service_role` клиентэд оруулахгүй. Нууц үг, түлхүүр, имэйлийг энэ баримтад бичихгүй.

Тестийг тусгаарлана:

- Цэвэр функц: гурван тооны томъёо, сарын хил, 2 оронтой тойролт. Сүлжээ байхгүй.
- Маршрут: зочин, хэрэглэгч, админ. Админ цэс зөвхөн админд.
- Форм: хоосон дүн, 0, 200-аас урт тэмдэглэл, дансгүй, ангилалгүй.
- Төлөв: хоосон, ачаалах, алдаа, офлайн. Жижиг өргөн ба өргөн дэлгэцийн зураг.
- Жинхэнэ хадгалалт: зөвхөн тусдаа туршилтын төсөл дээр. `rahymsygjwytwludoucq` руу автомат тест холбохгүй. `scripts/rls-test.mjs`-ийг тэр төсөл дээр ажиллуулахгүй.
- Expo Go эсвэл эмулятор дээр харсан бол «харсан» гэж бичнэ. Үгүй бол «хараахан үгүй».

## 12. Шийдвэр

- Гурван тооны томъёо дээрх 4-р хэсэгт түгжигдсэн. Нийлбэр зөвхөн MNT. Төсөвгүй зарлага «Төсвөөс үлдсэн»-д орохгүй.
- Дансны анхдагч нь нэрээр эрэмбэлсэн эхний данс. Шинэ «анхдагч данс» багана байхгүй.
- Харанхуй горим л батлагдсан.
- Одоогийн хайлт, шүүлт, эрэмбэ, хуудаслалт хэвээр. Нэмэлт шүүлт зохиохгүй.

- Хичээлийн хүснэгтийн сэдэв шинэчлэгдсэн эсэх баталгаажаагүй, дуусаагүй. Дараа нь холбогдсон эх сурвалжийг зөвхөн уншиж шалгаж болно. Хүснэгт засах, илгээх нь хэрэглэгч зөвшөөрсний дараа. Автоматаар багш руу илгээхгүй.
