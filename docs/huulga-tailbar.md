# Хуулгыг яаж уншдаг вэ (оюутны тайлбар)

Энэ текст хамгаалалтын «энэ мөр юу хийдэг вэ?» гэсэн асуултад зориулав.

## 1. PDF-ээс текст

`src/lib/pdf/extractText.ts` файлыг байтаар уншина. `%PDF` биш бол гэмтсэн. `/Encrypt` байвал нууц үгтэй гэж зогсоно.

Хуудасны `Contents` урсгалыг `fflate` задлана. Хаан банкны фонт нь `Identity-H`: тэмдэгт бүр 2 байт. `ToUnicode` хүснэгт тэр кодыг Монгол үсэг болгоно. Үр дүн нь `{x, y, text}` цэгүүд. Зурган PDF дээр үсэг бараг байхгүй тул «сканнер» гэж буцаана.

Энэ алхам утсан дээр ажиллана. Сервер рүү PDF явуулахгүй.

## 2. Мөр болгох

`src/lib/statements/khanBank.ts` ижил `y` дээрх үгсийг нэг мөр болгоно. Огноо (`2026.01.03`), цаг, гурван мөнгөн дүн (эхний үлдэгдэл, гүйлгээ, эцсийн үлдэгдэл) байна. Дүн `1,234.56` хэлбэртэй, дотор нь таслал, ард нь яг 2 орон.

Тооцоог төгрөгийн **мөнгөөр** (бүхэл тоо) хийнэ. `0.10 + 0.20 = 0.30` гэж float дээр итгэхгүй.

Шалгалт: `эхний + дүн = эцсийн`, дараагийн мөрийн эхний үлдэгдэл өмнөх эцсийн үлдэгдэлтэй тэнцүү. «Нийт дүн» мөр гүйлгээ биш, нийлбэрийн шалгалт. Таарахгүй мөрийг жагсаалтаас устгахгүй.

Дараагийн хуудсанд хүснэгтийн толгой давтагдахгүй. Урт тайлбар дараагийн мөрөнд зөвхөн баруун баганад үргэлжилнэ. Түүнийг өмнөх гүйлгээний утга дээр залгана.

## 3. Ангилал

`type` нь мөнгө орсон (`income`) эсвэл гарсан (`expense`). Үлдэгдэл үүгээр өөрчлөгдөнө.

`economic_kind` нь өөр асуулт:

- `normal` — жинхэнэ орлого эсвэл зарлага. Сарын тайланд орно.
- `transfer` — данс хооронд. Үлдэгдэлд орно, зарлагад орохгүй.
- `savings` — хадгаламж руу/аас. Мөн адил, зарлага биш.
- `refund` — буцаалт. Орлого биш, тусад нь харагдана.
- `unclassified` — үг танигдаагүй. Хэрэглэгч засна. Тайлангийн орлого/зарлагад орохгүй.

`classify.ts` зөвхөн үг харна. 5 сая төгрөг гээд цалин гэж нэрлэхгүй. «шилжүүлэг» ганцаараа байвал өөр хүнд төлсөн байж болзошгүй тул `unclassified`.

## 4. Хадгалах ба давхардал

Хадгалах товч дарах хүртэл санд юу ч бичигдэхгүй.

`commit_statement_import` нэг транзакц. Дунд нь алдаа гарвал эхний үлдэгдэл, багц, гүйлгээ бүгд буцна.

Давхардлын түлхүүр: огноо + цаг + чиглэл + дүн + үлдэгдэл. Unique index. Ижил кофе хоёр удаа, өөр үлдэгдэлтэй бол хоёр мөр. Яг адилхан мөрийг дахин оруулбал алгасна. Нэг файлын SHA-256 дахин ирвэл багцыг бүхэлд нь давхар гэж үзнэ.

Эхний үлдэгдлийг гүйлгээ болгож нэмэхгүй. Данс хоосон, үлдэгдэл нь 0 байвал л хуулгын эхний үлдэгдлийг тавина. Өөр дүн байвал дарахгүй.

## 5. Буцаах

`rollback_statement_import` зөвхөн `import_id` таарсан мөрийг устгана. Гараар нэмсэн мөр `import_id` null тул үлдэнэ. Бидний тавьсан эхний үлдэгдэл хэвээр байвал хуучин 0 руу буцаана. Хэрэглэгч дараа нь үлдэгдлээ өөрчилсөн бол түүнийг дарахгүй.

## 6. Юу хийж чадахгүй вэ

Зурган PDF, нууц үгтэй PDF, Excel, Голомт болон бусад банк. Сүлжээгүй үед уншиж болно, хадгалж болохгүй. Production миграцийг энэ PR автоматаар ажиллуулахгүй.
