# Хуулга оруулах — батлагдсан дизайн

Батлагдсан урсгал: **PDF сонгох → төхөөрөмж дээр задлах → шалгах/засах → хадгалахыг тусад нь дарах → тайлан**. Давхардлыг танина. Шилжүүлгийг энгийн зарлагаас тусгаарлана. Гараар оруулах CRUD, нэвтрэлт, SWM231-ийн одоогийн хамгаалалт хэвээр.

Төлбөр (QPay/Stripe) болон камер/баримтын зургийг энэ өөрчлөлтөд хийгээгүй. Тэдгээр нь Хамгаалалт-2-ын тусдаа ажил.

## Яагаад локал PDF

Хаан банкны хуулга нь зураг биш, FlateDecode текст PDF. `fflate` + жижиг PDF уншигч Expo Go (iOS/Android) болон вэб дээр ажиллана. Worker, DOM, төлбөртэй AI шаардахгүй. Файл хэрэглэгчийн төхөөрөмжөөс гарахгүй. `service_role` клиентэд байхгүй.

## Дэмжих формат

Дэмжинэ:

- Хаан банкны дансны хуулга (текст)
- олон хуудас (толгой ихэвчлэн эхний хуудсанд, хөл хуудас бүр дээр)
- мөр дамжсан гүйлгээний утга
- орлого (нэмэх) ба зарлага (хасах)
- `1,234.56` хэлбэрийн 2 орны дүн
- мөр бүрийн эхний үлдэгдэл + дүн = эцсийн үлдэгдэл

Дэмжихгүй, ойлгомжтой алдаа өгнө:

- нууц үгтэй PDF
- сканнердсан эсвэл зурган PDF
- гэмтсэн файл, PDF биш файл
- 8 МБ, 25 хуудас, 2500 мөрөөс их
- Голомт болон бусад банк. «Бүх PDF-ийг уншина» гэж хэлэхгүй

Танигдаагүй мөнгөн мөрийг чимээгүй хаяхгүй. Дэлгэцэнд гаргаж, засах эсвэл хасахыг шаардана.

## Ангилал

Хоёр өөр ойлголт:

| | Мөнгөний чиглэл | Эдийн засгийн утга |
|---|---|---|
| Хаана хадгалагдах вэ | `transactions.type` = income / expense | `economic_kind` |
| Юу вэ | Дансанд мөнгө орсон уу, гарсан уу | Зарцуулалт уу, шилжүүлэг үү |
| Үлдэгдэл | Орлого нэмнэ, зарлага хасна | Бүгд үлдэгдэлд орно |
| Сарын орлого/зарлага | Зөвхөн `normal` | transfer, savings, refund, unclassified орохгүй |

Их дүнгээр ангилахгүй. Үг танигдахгүй бол `unclassified`, ангилал хоосон. Хэрэглэгч засна.

## Давхардал ба эхний үлдэгдэл

Хурууны хээ: огноо, цаг, чиглэл, дүн (мөнгө), гүйлгээний дараах үлдэгдэл. SHA-256. Тайлбар ороогүй тул утгыг зассан ч дахин оруулахад давхардахгүй.

Ижил цагт ижил дүнтэй хоёр худалдан авалт үлдэгдлээрээ ялгаатай тул хоёулаа үлдэнэ. Давхардсан файл эсвэл давхцсан хугацаа unique index дээр алгасна. Нэг файлын SHA-256 дахин орвол багцыг бүтнээр нь «аль хэдийн орсон» гэж буцаана.

Эхний үлдэгдлийг гүйлгээ болгож оруулахгүй. Данс хоосон, `initial_balance = 0` үед л хуулгын эхний үлдэгдлийг тавина. Өөр үлдэгдэл эсвэл өмнөх гүйлгээ байвал дарахгүй.

Буцаах: зөвхөн тухайн багцын `import_id`. Гараар оруулсан мөр (`import_id` null) үлдэнэ. Эхний үлдэгдлийг бид тавьсан хэвээр байвал хуучин утгыг сэргээнэ.
