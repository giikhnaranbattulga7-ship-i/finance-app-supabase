# Хамгаалалт-1 — Илтгэлийн текст (5 мин PPT + 3 мин demo + 2 мин асуулт)

> Слайд бүр ~20 секунд. Нийт 15 слайд ≈ 5 минут. Цаг хэтэрвэл 7, 10-р слайдыг товчлоорой.

**1. Нүүр (15 сек)**
Сайн байна уу. Би «Хувийн санхүүгийн апп» төслөө танилцуулна. React Native Expo, TypeScript, Expo Router болон Supabase ашиглан хийсэн full-stack мобайл апп.

**2. Асуудал ба зорилго (25 сек)**
Оюутнууд мөнгөө хаана зарцуулснаа мэддэггүй, бэлэн мөнгө, карт, хадгаламж нь тусдаа байдаг. Банкны апп зөвхөн өөрийн гүйлгээг харуулдаг, ангиллын төсөв байхгүй. Миний апп бүх дансыг нэгтгэж, гүйлгээг ангилал, шошгоор бүртгэн, сарын төсвөөр хянах боломж олгоно.

**3. Шаардлага (25 сек)**
Удирдамжийн Хамгаалалт-1-ийн шаардлагууд болох бүртгэл, нэвтрэлт, SecureStore, 6-аас дээш хүснэгт, CRUD, хайлт шүүлт, админ хэсэг, RLS-ийг бүгдийг хийсэн. Төлбөр, push, камерыг Хамгаалалт-2-т хийнэ — үүнд зориулж premium_orders хүснэгт бэлэн байгаа.

**4. Хэрэглэгчийн төрөл (20 сек)**
Гурван role бий. Зочин бүртгэлгүйгээр үндсэн ангиллыг хайж үзнэ. Хэрэглэгч өөрийн өгөгдлөө CRUD хийнэ. Админ апп доторх самбараас хэрэглэгч, захиалга, орлогын статистикийг харна. Role нь profiles хүснэгтэд хадгалагдана.

**5. Архитектур (20 сек)**
Дэлгэц нь services давхаргыг дууддаг, services нь supabase-js-ээр зөвхөн anon түлхүүр ашиглан хүсэлт явуулна. Хамгаалалт серверт буюу RLS дээр хийгдэнэ, учир нь апп-ыг задалж уншиж болно. Session нь SecureStore-д хадгалагдана.

**6. User flow (20 сек)**
Апп нээгдэхэд SecureStore-д session байгаа эсэхийг шалгана. Байхгүй бол нэвтрэх, бүртгүүлэх, нууц үг сэргээх эсвэл зочин горим. Нэвтэрсний дараа 5 табтай: Нүүр, Гүйлгээ, Төсөв, Данс, Профайл. Админ бол профайлаас админ самбар руу орно.

**7–8. Дизайн (30 сек)**
Figma-д design system гаргасан: үндсэн ягаан-цэнхэр өнгө, орлого ногоон, зарлага улаан. Товч, оролт, chip, карт компонентууд кодонд яг адилхан src/components-д байгаа. Энд нэвтрэх, нүүр, гүйлгээний жагсаалт, форм, төсөв, админ дэлгэцүүд харагдаж байна.

**9–10. ERD (40 сек)**
Нийт 8 хүснэгт. profiles нь auth.users-тэй 1:1. Нэг хэрэглэгч олон данс, гүйлгээ, төсөв, шошготой — 1:N. Нэг данс олон гүйлгээтэй. Гүйлгээ ба шошго олноос олон холбоотой тул transaction_tags завсрын хүснэгт composite primary key-тэй. CHECK-ээр дүн 0-ээс их, UNIQUE-ээр нэг ангилалд сард нэг төсөв байхаар хязгаарласан. Үлдэгдлийг account_balances view тооцно.

**11. Auth + SecureStore (25 сек)**
Бүртгүүлэхэд trigger profiles мөрийг автоматаар үүсгэнэ. Нууц үг сэргээх линк апп руу code-той буцаж ирээд PKCE-ээр session болно. SecureStore 2KB хязгаартай тул JWT-г хэсэглэж хадгалдаг adapter бичсэн. Stack.Protected-оор нэвтрээгүй хүн дотор дэлгэц рүү, админ биш хүн админ самбар руу орж чадахгүй.

**12. RLS (30 сек)**
Бүх 8 хүснэгтэд RLS асаалттай. using нь аль мөрийг харахыг, with check нь ямар мөр бичихийг шийднэ. Гүйлгээ нэмэхэд данс нь өөрийнх эсэхийг шалгадаг. is_admin функц security definer тул policy дотор recursion үүсгэхгүй. Хэрэглэгч өөрийгөө админ болгохыг trigger хориглоно. 36 тестийг бодит Supabase дээр ажиллуулж бүгд амжилттай.

**13. Кодын бүтэц (20 сек)**
app хавтсанд дэлгэцүүд, components-д дахин ашиглагдах UI, services-д өгөгдлийн сангийн query, context-д auth state байна. transaction/[id] нэг дэлгэц нэмэх, засах хоёр горимтой.

**14. Demo төлөвлөгөө (10 сек)**
Одоо 3 минутын demo үзүүлье.

**15. Дүгнэлт (15 сек)**
Хамгаалалт-2-т QPay sandbox, webhook, push мэдэгдэл, Storage, EAS Build нэмнэ. Баярлалаа.

## Demo (3 мин) — алхам бүр
1. **(Бэлтгэл)** Expo Go асаалттай, дэлгэц дамжуулалт тохирсон, `demo.user@financeapp.test / Demo1234!`. Supabase Dashboard өөр tab-д нээлттэй.
2. Нэвтрэх дэлгэц → «Зочноор үзэх» → ангилал хайх («хоол») → Нэвтрэх/Бүртгүүлэх.
3. Буруу нууц үгээр нэвтрэх → Монгол алдаа → зөв нууц үгээр нэвтрэх.
4. Нүүр: нийт үлдэгдэл, сарын орлого/зарлага, ангиллын график.
5. **+** → дүн хоосон «Нэмэх» дарж validation үзүүлэх → 20000, Бэлэн мөнгө, Хоол хүнс, тэмдэглэл «Demo», #сургууль → Нэмэх.
6. Гүйлгээ таб: «Demo» хайх → Зарлага шүүлт → «Их дүн» эрэмбэ → доош татаж шинэчлэх.
7. Гүйлгээ дээр дарж дүнг засах → Хадгалах → дахин орж «Устгах» → баталгаажуулах цонх → Тийм.
8. Төсөв таб: Зугаа цэнгэл 133% улаан. Данс таб: үлдэгдэл шинэчлэгдсэн.
9. Supabase Dashboard → Table editor → transactions мөр, Authentication → Policies-г үзүүлэх.
10. Профайл → Гарах (баталгаажуулах) → `demo.admin@financeapp.test` нэвтрэх → Профайл → Админ самбар.

**Нөөц төлөвлөгөө:** Интернэт/Expo Go асуудалтай бол https://finance-app-supabase.vercel.app web хувилбараар үзүүлнэ.
